# Kanzen Master N4 Grammar App

This is the GitHub Pages study app for the N4 book. `index.html` loads answers and exercises from `data.json`.

## Source material

- `books/Shin-Kanzen-Master-N4-Bunpou.pdf` is the full source book.
- `pages/grammar/` contains selected source pages as PNGs.
- `pages/answers/` contains PDF pages 171–183 rendered as PNGs from the answer section.
- `tools/create_app.py` regenerates the static app files when run from this folder.
- `archive/` contains an earlier data snapshot and a draft structure file; the app uses the root `data.json`.
